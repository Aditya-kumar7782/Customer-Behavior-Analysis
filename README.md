# 🛒 Customer Behavior Analysis

## 📌 Project Overview

This project analyzes customer behavior using an e-commerce transaction dataset. The objective is to identify customer segments, understand purchasing patterns, and analyze churn risk using data analytics and machine learning techniques.

---

## 🎯 Objectives

- Clean and preprocess customer transaction data
- Perform Exploratory Data Analysis (EDA)
- Conduct RFM (Recency, Frequency, Monetary) Analysis
- Segment customers using K-Means Clustering
- Analyze churn risk
- Provide business recommendations

---

## 🛠️ Technologies Used

- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

---

## 📊 Dataset

- 250,000 e-commerce transactions
- 49,661 unique customers
- Time Period: January 2020 – September 2023
- Source: [Kaggle - Customer Behavior Analysis](https://www.kaggle.com/datasets/bhanupratapbiswas/customer-behavior-analysis)

---

## 📈 Analysis Performed

- Data Cleaning
- Feature Engineering
- Exploratory Data Analysis
- RFM Analysis
- K-Means Customer Segmentation
- Purchase Pattern Analysis
- Churn Risk Analysis

## 💡 Key Insights

- High-value customers contribute the largest share of revenue.
- Customer segmentation helps identify loyal and at-risk customers.
- Purchase behavior was analyzed using RFM metrics.
- The provided churn label showed no meaningful correlation with actual RFM behavior, suggesting that real churn risk should be tracked through behavioral signals rather than the label itself.
- Actionable business recommendations were provided to improve customer retention.
